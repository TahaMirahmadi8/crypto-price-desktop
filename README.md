# Crypto Price Desktop

![Python Version](https://img.shields.io/badge/python-3.x-blue.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)
![Framework](https://img.shields.io/badge/framework-CustomTkinter-orange.svg)

A modern, high-performance desktop application designed for real-time cryptocurrency price tracking. Built with a focus on sleek aesthetics and lightning-fast data retrieval.

---

## Key Features

*   **Modern Dark Mode UI**: A polished, professional interface built with `CustomTkinter`.
*   **Market Snapshot**: Instant view of the **Top 40 cryptocurrencies** by market cap upon startup.
*   **Instant Search**: High-speed filtering to find any crypto asset in milliseconds.
*   **Real-time Data**: Live price updates fetched via high-performance API integration.

## Tech Stack

*   **Language:** Python 3.14
*   **GUI Framework:** CustomTkinter
*   **Data Handling:** `Requests` / `JSON`
*   **API:** Nobitex API
